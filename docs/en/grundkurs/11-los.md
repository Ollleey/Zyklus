# Your first job

Now you know the basics. This is how a job works in the game:

1. **Read mail and datasheet** – what should the plant do, which devices are there?
2. **Fit the cabinet** – CPU and modules on the DIN rail, wire the devices. Every module costs
   something (¤).
3. **Program** – in SCL, FBD or LAD. Below it says whether the program compiles without errors.
4. **Test bench** – choose a test case, **▶ Start**, watch the timing chart. **Cycle** advances one
   cycle, under **Watch** you see values live.
5. **Verify** – all test cases run. Passed? Then you see cost, energy and size of your solution
   compared to others.

## Tips for the start

- **Start small**: one line first, try it, then the next.
- **The timing chart doesn't lie**: if the output doesn't come, look which input is missing.
- **Read error messages**: they name the line and usually what is missing.
- **The handbook** (📖 in the inbox) explains all blocks and statements.
- Stuck? A job won't run away – a break often helps more than trying.

Job 0 “Introduction: lights on” guides you through everything with a step card. Because you did the
basics course, the card explains every step in more detail.
