Leistungstest Sandkasten: 30 Bauteile, 50 Werkstücke im Stau, eingestellt ×100
Messung: scripts/sandbox-shots.mjs gegen den Produktions-Build (npm run build, npm run preview)

Simulation im Web Worker (seit Ausbau W1), parallel lief ein anderes Spiel:
  60,2 Bilder/s, Simulation ×71

Frühere Messungen im Hauptthread:
  ohne Fremdlast, Budget 11 ms je Bild:           59,7 Bilder/s, Simulation ×47
  mit Fremdlast, anpassendes Budget (max. 12 ms):  51,1 Bilder/s, Simulation ×6

Die Darstellung bleibt flüssig, weil der Worker rechnet. ×100 wird in diesem Extremfall (alle
Teile im Stau, 15 Sensoren) noch nicht ganz erreicht; die Simulation läuft dann so schnell, wie
der Worker rechnen kann. Die Aufträge der Kampagne rechnen weiter im Hauptthread.
